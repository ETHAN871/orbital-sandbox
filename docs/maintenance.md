## 模型局限与原说明的谬误

1. **这是平面内的软化逆平方相互作用。** 坐标和时间使用像素与模拟秒，G 无现实单位标定；既不是严格二维 Poisson 引力（对数势），也不是太阳系尺度模型。默认动力学用引力冲量加 Rapier 接触，并非原 README 所说的 Velocity Verlet；只有冻结背景的预测使用 Verlet。
2. **“电荷”只决定源的作用。** `a_i = G q_j m_j (r_j-r_i)/(r²+s²)^(3/2)`，`s=max(R_i+R_j,ε)`。目标的 q 不乘进去，异号或中性组合通常不满足作用反作用，所以不能期待封闭系统动量／能量守恒。同号、无碰撞、无固定体才适合上述守恒测试。没有擅自把这一游戏规则改成库仑力。
3. **半径改变的不止碰撞几何，还改变远场软化。** `ε=0` 也不会关闭有限半径物体的软化；紧轨道不服从未软化 Kepler 定律。不存在“一改 ε 就得到真实点质量”的保证。
4. **引力膜不是广义相对论或精确势能图。** 默认膜使用艺术化核、绝对源强、视觉光照和密度细分；引斥可能都表现为凹陷。legacy 参考势仅用 ε，实际 pair force 还取决于目标半径，因此二者梯度不相同。旧文档声称三处公式“bit-identical”不成立；CPU float64 与 GPU float32 也不可能普遍逐位相同。
5. **周期边界是有限近似。** 动力学采用单个最短镜像，半周期切换面上的力方向不连续；不是无限周期重力的 Ewald 求和。旧图示九镜像截断求和既不等于最短镜像动力学，也不严格周期连续。全屏膜修复覆盖并不把视觉模型变成精确物理；其网格在某些参数下仍可出现接缝／密度跳变。
6. **接触是近似约束。** 镜像去重修复了双算冲量，但对多体同时跨缝接触，代理体与真实体仍不构成同一个全局约束系统。高密度、巨半径（接近半个 viewport）、重叠生成、低刚度和高 G 可出现渗透或残余振动，不能声称“绝不爆炸”或“完全不折叠”。CCD 降低实体穿透风险，但没有提供黑洞传感器的连续扫掠吞噬。
7. **黑洞是删除规则。** 没有质量增长、动量合并、潮汐、光速限制或事件视界。固定物体、非弹性接触、生成消重叠阻尼、删除越界物体都会改变系统能量／动量。
8. **预测不是实际多体演化。** 其他物体冻结，不求它们的反作用与行星碰撞，因此长时预测、密集场景和运动中的吸引源会明显偏离。
9. **性能保护会改变精度与墙钟速度。** 固定 dt 保留，但 AQM 降低接触迭代，重负载限制子步并丢掉整步欠账；UI 现在称“目标倍率”。直接引力仍是 O(N²)；GPU 包含 CPU↔GPU 数据搬运，不保证某 N 以上必然更快。场图最多处理 128 个条目，部分模式的镜像还会占名额。
10. **工程限制仍存在。** Rapier 使用远程固定版本 CDN；断连后本地求解器不保证接触结果等价。无场景持久化或导入、无长期精确星历、无跨浏览器浮点确定性。已移除声称存在的 Barnes–Hut 路径和旧阶段蓝图，避免误导维护。

Rapier 的力和冲量是不同 API：力持续存在直到 resetForces，冲量直接改速度。旧代码注释曾把 addForce 的实验观察解释为“API 实际按冲量工作”，缺乏依据；现已更正，继续明确使用 `m*a*dt` 冲量。参考：[力与冲量](https://rapier.rs/docs/user_guides/javascript/rigid_body_forces_and_impulses/)、[休眠行为](https://rapier.rs/docs/user_guides/javascript/rigid_body_sleeping/)、[接触过滤](https://rapier.rs/docs/user_guides/javascript/advanced_collision_detection/)。
